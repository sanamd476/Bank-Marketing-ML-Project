# Bank Marketing Subscription Prediction

## Project Overview
This project uses Machine Learning to predict whether a customer will subscribe to a bank term deposit based on customer information and marketing campaign data.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Cleaning
4. Handling Missing Values
5. Removing Duplicate Records
6. Categorical Encoding
7. Feature Selection
8. Train-Test Split
9. Feature Scaling
10. Logistic Regression Model
11. Model Evaluation
12. Model Saving using Joblib

## Machine Learning Algorithm
Logistic Regression with balanced class weights.

## Model Performance
- Accuracy: 69.14%
- Class 1 Precision: 0.71
- Class 1 Recall: 0.59
- Class 1 F1-score: 0.64

## Project Files
- `Bank_Marketing_Subscription_Prediction.ipynb` – Complete project notebook.
- `bank_marketing_model.pkl` – Saved trained model.

## Conclusion
The model predicts customer subscription behaviour and demonstrates an end-to-end Machine Learning workflow using Python and Scikit-learn.
